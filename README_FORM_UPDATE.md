# Titanium Market — форма подачи объявлений

В этой версии форма подачи объявления переработана:

- категории находятся сверху в одну горизонтальную линию;
- для автомобилей добавлен поиск с подсказками полного названия;
- список автомобилей разделён на обычные, уникальные, премиум, донатные, мотоциклы, премиум-мотоциклы, квадроциклы и велосипеды;
- добавлены варианты тюнинга [У], [П], [Э], [К], [М], [ЭП], [БП], [БЭП], [Б200], [БЭ200П], [БПК], [БЭПК], [БК200], [БЭК200П], [Б], [БЭ], [200], [200П], [Full];
- добавлен уровень скорости/ускорения [S];
- добавлена отметка «с элементами тюнинга»;
- для автомобилей город не запрашивается;
- для недвижимости доступны 7 классов дома, город и район;
- для бизнесов доступны тип бизнеса, город и район;
- для недвижимости и бизнеса добавлен расширенный список районов и расположений.

Названия 7 классов домов в исходном ТЗ не были указаны, поэтому в интерфейсе временно используются классы 1–7.

## Запуск

```powershell
npm install
npm run build
$env:DATABASE_URL = "ВАША_СТРОКА_SUPABASE"
npm start
```

Не добавляйте `.env` и реальные пароли в Git.
