Titanium Market — точечное изменение формы автомобилей

Заменить только:
  src/App.vue

Не заменять:
  src/style.css
  server.js
  базу данных
  остальные файлы

Изменения:
- категории в форме подачи остаются кнопками;
- для автомобилей поле названия стало выбором/автоподсказкой по списку автомобилей;
- для автомобилей нет поля города;
- добавлены тюнинг, ускорение и скорость;
- выбранные значения автоматически добавляются в существующее поле description;
- каждая строка заканчивается точкой с запятой;
- новые поля не отправляются в БД как отдельные колонки.
